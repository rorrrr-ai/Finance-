# خريطة المال — Money Map

موقع تعليمي تفاعلي (عربي / English) لطالب المالية: المؤسسات المالية، القوائم المالية الثلاث، أرقام حقيقية للسنة المالية 2025، النمذجة المالية، المخاطر، المالية الدولية، المسارات المهنية، وخريطة CFA Level I.

- `index.html` — التصميم وهيكل الصفحة
- `app.js` — التنقل والحاسبات والاختبارات
- `data-inst1.js`, `data-inst2.js` — محتوى 17 مؤسسة
- `data-lab.js` — مختبر القوائم (الراجحي، المراعي، Apple) وأدوات المحلل
- `data-market.js` — القطاعات، نماذج العمل، دليل القطاع المالي السعودي، السلالم الوظيفية
- `app-more.js` — صفحات المختبر والأدوات والقطاعات والدليل والمسارات
- `data-deep.js` — مكتبة الصفقات، الأزمات، الأفكار الكبرى، قائمة القراءة، خطة السنة
- `app-deep.js` — صفحات الصفقات والأزمات والمكتبة والخطة
- `data-learn.js` — القوائم، الأرقام الحقيقية، النمذجة، المالية الدولية، المسارات، القاموس، المصادر
- `PROMPT.md` — البرومبت الذي بُني عليه الموقع
